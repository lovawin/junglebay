06
Race Mechanics

Fair but rewarding.

⚡

Speed Boosts

Intensity 1-10. Each adds +25 base speed. Stack multiple for maximum velocity.

🛡️

Shields

Block random race hazards. Each shield reduces finish time penalty by 5%.

🌊

Shortcuts

Skip 10-30% of the race distance. The ultimate edge for savvy racers.

⚖️ The Fairness Model

Base speed scales logarithmically with tokens locked — whales have an advantage but it's diminishing. A small depositor with great power-ups can beat a whale with none. Deterministic on-chain computation using wallet + tokens + power-ups + block data as seed.
